개인정보처리방침

시행일: 2026년 11월 7일

Sayday는 개발자가 개인적으로 쓰려고 만드는 일정 앱이며, 지금은 기술 검증 단계입니다. 이 문서는 현재 앱이 실제로 하는 일만 설명합니다. 다루는 정보가 늘어나면 기능을 켜기 전에 이 문서를 먼저 고칩니다.

요약

  • Google 권한은 앱이 만든 캘린더를 다루는 calendar.app.created 하나만 요청합니다.
  • 정보를 판매하거나 광고에 쓰지 않고, 아래에 적은 외부 서비스 외의 제3자에게 넘기지 않습니다.
  • Google 연결은 언제든 해제할 수 있고, 해제하면 서버의 Google 토큰을 지웁니다.

처리하는 정보

로그인 정보
이메일과 비밀번호입니다. Supabase 인증 서비스가 보관합니다. 앱은 비밀번호를 기기에 저장하지 않고, 로그인 유지에 필요한 세션 토큰만 Android 보안 저장소와 macOS 키체인에 보관합니다.
메모
기기 안의 데이터베이스에 저장합니다. 사용자가 보내기를 누를 때만 서버로 전송해 기기 간에 공유합니다. 서버의 메모는 앱 수준에서 암호화하지 않으므로 프로젝트 관리자인 개발자가 볼 수 있습니다.
Google 연결 정보
Google 장기 토큰과 권한 범위, 연결한 기기 종류, 만료 시각, 연결 시각입니다. 토큰은 서버에 AES-256-GCM으로 암호화해 저장하고, 앱이 설치된 기기에는 저장하지 않습니다.
알림
기기 안에서 예약하며 알림 내용을 서버로 보내지 않습니다.
사용량과 운영 기록
허용된 사용자 목록과 기능별 사용 횟수를 서버에 저장합니다. 서버 함수 기록에는 동작 이름, 상태 코드, 오류 코드를 남기며 토큰과 승인 코드는 남기지 않습니다. 서비스 제공업체가 요청 시각 같은 접속 정보를 자체적으로 기록할 수 있습니다.

Google 사용자 데이터

  • 접근 범위: Google은 이 권한을 보조 캘린더를 만들고 그 캘린더의 일정을 보고, 만들고, 바꾸고, 지우는 권한으로 설명합니다. 이 권한으로 기본 캘린더의 일정을 읽을 수 없음은 시험으로 확인했습니다.
  • 사용: 지금은 연결 상태를 확인하고, 시험용 캘린더와 시험 일정을 만들고 지우는 데만 씁니다.
  • 저장: 위에 적은 연결 정보만 저장합니다. 캘린더와 일정의 내용은 서버에 저장하지 않습니다.
  • 공유: 토큰 보관에 쓰는 Supabase 외의 제3자에게 넘기지 않습니다. 광고나 AI 모델 학습에 쓰지 않으며, AI 제공업체에 보내지 않습니다.

Sayday의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함해 이 정책을 따릅니다.

이용하는 외부 서비스

  • Supabase (서울 리전): 로그인, 데이터베이스, 서버 함수
  • Google: 계정 승인과 Google Calendar API
  • GitHub Pages: 이 안내 페이지 호스팅. GitHub는 방문자의 IP 주소를 보안 목적으로 기록합니다.

문장 해석을 위한 AI 기능은 아직 앱에 연결되어 있지 않습니다. 연결하기 전에 어떤 정보가 어디로 전송되는지 이 문서에 먼저 적습니다.

보관과 삭제

  • Google 토큰: 연결을 해제하면 Google에 권한 회수를 요청하고 서버의 토큰을 지웁니다. 다른 기기에서 다시 연결하면 이전 토큰은 서버에서 지워지지만, 그 토큰의 Google 쪽 권한까지 회수하지는 않습니다.
  • Google 계정에서 직접 회수: Google 계정의 서드파티 연결 화면에서 Sayday의 권한을 언제든 없앨 수 있습니다.
  • 앱이 만든 캘린더: 연결을 해제해도 자동으로 지우지 않습니다. 남아 있다면 Google 캘린더에서 지울 수 있습니다.
  • 계정과 서버 메모: 앱 안에는 아직 삭제 기능이 없습니다. 요청하면 개발자가 계정을 삭제하며, 이때 서버의 메모와 Google 토큰도 함께 지워집니다. 프로젝트를 끝낼 때도 삭제합니다.
  • Android 기기의 데이터: 앱을 지우면 함께 삭제됩니다. 다만 Android 자동 백업이 켜져 있으면 메모가 사용자의 Google 백업에 포함될 수 있습니다.
  • Mac의 데이터: 앱을 지워도 응용 프로그램 지원 폴더의 메모와 키체인의 세션 토큰이 남습니다. 앱 안에서 로그아웃하면 세션 토큰이 지워지고, 메모는 ~/Library/Application Support/local.sayday.m0 폴더를 지우면 삭제됩니다.

보호 조치

통신에는 HTTPS를 사용합니다. 사용자별 접근 제어로 다른 사용자의 데이터를 읽지 못하게 하고, Google 토큰은 앱에서 직접 읽을 수 없으며 서버 함수로만 다룹니다. 암호화 키는 데이터베이스와 분리해 서버 함수의 비밀 저장소에 보관합니다. 다만 어떤 시스템도 완벽한 보안을 보장할 수는 없습니다.
